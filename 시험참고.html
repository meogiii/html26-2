H01 사진 → 코드: 이 순서로 구현

  1. 제목, 문단, 목록, 표, 폼 순서를 먼저 적는다. 글자 내용과 줄바꿈을 맞춘다.
  2. 큰 제목=h1~h6, 문단=p, 문단 안 줄바꿈=br, 구분선=hr.
  3. 표는 병합 전 전체 열 수부터 세고 각 행의 칸을 작성한다. H05 참고.
  4. 폼은 입력 종류·기본값·선택 상태·그룹 테두리를 구분한다. H07 참고.
  5. 구조 완성 후 색·굵기·정렬·크기를 맞춘다. 기본 화면이면 전체 여백 초기화를 하지 않는다.
  6. 저장하고 브라우저에서 비교한다. 전체 위치 → 표 → 폼 → 작은 글자 순으로 수정.

H08 폼에서 헷갈리는 것

속성뜻·주의
value / placeholdervalue는 실제 초기값. placeholder는 빈칸일 때만 보이는 안내이며 제출값이 아니다.
required필수 입력. radio는 그룹 중 하나, checkbox는 해당 항목을 반드시 체크.
maxlength최대 글자 수. 최소 글자 수가 아니다. number의 수치 상한을 정하지 않는다.
pattern입력값 전체 형식 검사. 빈 값도 막으려면 required 추가. tel 자체는 전화번호 형식을 검사하지 않는다.
readonly수정 불가, 포커스·복사 가능, name이 있으면 전송. 주로 텍스트 입력에 사용. select/checkbox에는 적용되지 않는다.
disabled비활성화, 제출 제외, required 검사 제외.
checked / selected체크박스·라디오는 checked, option은 selected.
불리언 속성required="false"도 속성이 존재해서 참이다. 해제하려면 속성 자체 삭제.
title보조 설명. 마우스를 올려도 보일 수 있고, 검사 오류 표시 방식은 브라우저에 따라 다르다.

정규식: [0-9] 숫자 한 글자 / [a-z] 소문자 한 글자 / {5} 정확히 5번 / {3,4} 3~4번 / + 1번 이상 / | 또는.
예: [0-9]{5} → 12345 통과, 1234 실패. pattern 속성에 /정규식/처럼 슬래시를 감싸지 않습니다.

표기법: userEmail(카멜) / UserEmail(파스칼) / user-email(케밥) / user_email(스네이크).
name은 camelCase, id·class는 kebab-case로 쓰면 편하지만 강제 규칙은 아닙니다.
class="card highlight"는 두 클래스입니다. CSS는 .card.highlight로 둘 다 있는 요소를 선택합니다.

H10 내 실습에서 고쳐야 할 부분

  • 0917실습: p 안에 h1/h3 등을 넣음 → 제목과 p를 나란히 분리. 브라우저가 자동으로 구조를 고쳐 여백이 달라질 수 있음.
  • 1001_index: h3로 열고 h5로 닫음 → 같은 태그로 닫기. email id 반복 → 각각 고유하게 만들기.
  • 1008_css선택자: ul 바로 아래 ol → ol을 해당 li 안으로 옮기기.
  • 1008실습: style은 head 안으로. 열지 않은 닫는 태그는 삭제. href가 비면 목적지로 이동하지 않음.
  • 1008실습: 입력·select의 name 누락 → 화면은 나와도 값 전송 안 됨. radio에는 서로 다른 value도 작성.
  • 1008실습: 회원번호 placeholder+disabled → 실제 값 표시·전송이 필요하면 value+readonly.
  • 123123: 파일을 받는 form → post에 enctype="multipart/form-data" 추가.
  • 1015 가상클래스: '동의합니다' 입력이 type="date" → 체크박스면 type="checkbox".
  • 이미지 width="200px" → HTML 속성은 width="200". CSS에서는 width: 200px;.
  • 0910의 font 태그 대신 span에 CSS font-family, color, font-size 사용.

교안 설명 보정: 자식 선택자로 부모 li에 color를 주면 손자 li도 상속으로 같은 색이 될 수 있습니다. '직접 선택되지 않음'과 '색이 안 바뀜'은 다릅니다. CSS C03 참고.
